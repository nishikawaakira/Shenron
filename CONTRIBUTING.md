# Contributing to Shenron

Before opening a pull request, run `make validate` from the repository root and make sure formatting, Clippy, and tests pass.

Use only synthetic data in tests and fixtures. Use documentation IP ranges and hostnames such as `example.test`. Do not paste real logs, IP addresses, or hostnames into issues or pull requests.

Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
